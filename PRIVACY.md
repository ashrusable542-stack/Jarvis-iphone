# Privacy & safety

- JARVIS iPhone Edition does not send chat messages, notes, tasks or preferences to a server.
- Local data is stored in this browser on this device.
- Export backups only to a place you trust.
- External links are opened only after a confirmation.
- No API keys, passwords, OTPs or payment credentials should be stored in JARVIS.
- The app is a personal prototype, not a safety-critical assistant.
